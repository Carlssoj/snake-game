# Snake

Minimal browser-based Snake game built with static HTML, CSS, and JavaScript.

## Run

1. Open `index.html` in a browser.
2. Play directly from the file system.

## Manual Verification

- Arrow keys move the snake.
- `W`, `A`, `S`, `D` also move the snake.
- The score increases only after eating food.
- The snake grows after eating food.
- The game ends when the snake hits a wall.
- In `Easy` mode, the snake crosses one wall and appears on the opposite side.
- The game ends when the snake hits itself.
- After a loss, `Rewind 4s` restores the game to a recent state a few seconds before the collision.
- Pause stops the game and Resume continues from the same point.
- Restart resets the board, score, and snake state.
- Boundaries behave the same on all four edges.
